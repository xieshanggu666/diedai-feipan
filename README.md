# 风盘战术 · Aerial Timeout

一个运行在浏览器里的单机飞盘战术对抗游戏。玩家不直接操作队员，而在开赛前绘制跑位路线、安排传接节点；比赛中只能使用有限暂停修改方案。全局风、局部风区、体力、盯防、拦截概率和 Matter.js 障碍碰撞会让同一套战术产生不同结果。

## 技术栈

- Phaser 3：球场、路线编辑、比赛与回放渲染
- TypeScript：完整类型约束
- Vite：开发与构建
- Matter.js：飞盘与实体障碍的物理碰撞、队员/飞盘刚体世界
- Howler：程序化生成的轻量音效
- Zustand：赛季、解锁、阵容、自定义球场与本地存档
- Vitest：路线校验、风场和比赛模拟测试

## 核心玩法循环

1. 进入 **赛季赛程**，选择或调整上场五人。
2. 打开 **绘制路线**：
   - 左侧选择队员。
   - 使用「路线」工具点击球场添加路径点，可拖拽路径点。
   - 绿色点是慢跑，黄色点是正常跑，红色点是冲刺；长冲刺会消耗更多体力。
   - 使用「传接」工具依次点击两名队员，创建黄色传接意图。
   - 「删除」工具可删除路径点或传接线。
   - 保存时会阻止穿过看台、树、网、箱体等不可达区域的路线。
3. 开始比赛后观察跑位、风对盘轨迹的影响、防守盯人和拦截。
4. 按 **空格** 或点击暂停按钮使用有限暂停（每场 2 次），临场修改路线。
5. 比赛结束后进入回放：
   - 拖动时间轴。
   - 点击绿色接球、金色得分、红色失误/断盘节点。
   - 选中红色失误节点后点「修改战术」，直接进入本场比赛的球场与阵容对应的战术编辑器，失误位置和涉事队员会自动标出。
   - 根据失误类型与发生前几秒的跑位修改方案，再进入下一场。
6. 胜利获得 3 分，平局 1 分，失利 0 分。赛季积分用于解锁新队员和新球场。

## 演示内容

### 四场单机赛季

- 晨光学院：慢热区域轮转，适合理解基础传接。
- 红隼竞技：紧逼人盯人，会惩罚长冲刺和停滞持盘。
- 铁网联队：高压拦截，适合练习折返与短传。
- 夜空巡航：风场阅读与反跑能力强，作为后期挑战。

### 四个内置半场

- 晨风屋顶场：基础障碍与微风。
- 城市铁笼场：压缩空间与中路阵风。
- 河岸交叉风场：横向河风、树和防护网。
- 夜光环碗场：强风、中央网架和高风险长传。

在「球场 / 风场」中可以新建自定义球场：添加看台、树、网、箱体与矩形风区，调整全局风向和风力。内置球场会被复制为一个可编辑改版，不会直接覆盖原始数据。

## 操作说明

| 场景 | 操作 |
| --- | --- |
| 路线编辑 | 选择队员后点击添加点；拖点调整；选择慢跑/正常/冲刺决定新点速度 |
| 传接编辑 | 点击传球队员，再点击接球队员；黄色圆点可删除传接 |
| 比赛 | `Space` 暂停/继续；暂停中可改路线；速度按钮可切换 0.5× / 1× / 2× |
| 回放 | 时间轴拖动，点击彩色节点跳转；支持上一节点/下一节点和倍速；选中红色失误节点后点「修改战术」直达本场战术编辑器 |
| 球场编辑 | 选择障碍或风区后点击球场；「移动」工具可拖拽 |

风向角度约定：`0°` 向右，`90°` 向下，`180°/-180°` 向左，`-90°` 向上。

## 设计说明

- 比赛使用固定步长模拟，所有关键帧都会进入回放，而不是只记录最终比分。
- 玩家计划的是“意图”：传接节点、提前量和路径不会强制成功，仍需通过接球、风、防守压力和拦截判定。
- 体力会影响末段速度；冲刺距离越长，被贴身防守追上的概率越高。
- 每个新比赛种子不同，随机偏差会影响出手、接球和断盘，因此同一路线需要根据复盘持续修正。
- 存档保存在浏览器 `localStorage` 中；侧边栏的「清空存档」可重置赛季与解锁内容。

## 已知边界

这是一套完整的单机战术原型，不包含联网对战、真实飞盘联盟规则或动画骨骼。演示比赛采用半场进攻视角：玩家每回合从左侧发起，防守方断盘/脱手会被快速换算为对手得分，以便把节奏集中在路线设计、暂停调整和复盘迭代上。
